## Session 3 - Testing AI & Reverse Prompting

Session 3 focused on testing AI responses, understanding how prompt framing can influence AI output, and learning how to verify AI-generated answers before trusting them.

The session included activities covering:

* Testing AI responses using confident and neutral prompts
* Understanding agreement bias and why AI confidence does not guarantee correctness
* Verifying code by compiling and running it before asking AI
* Reverse prompting and self-critique of AI responses
* Comparing AI responses against independently verified evidence
* Understanding professional risks of unverified AI output
* Developing a personal rule for verifying AI-generated information

The main principle of the session was:

> Ask. Verify. Then trust.

Detailed information and the activities can be found in the [Session 3 folder](Session-3/).

## Session 4 - From C to Python with AI

Session 4 focused on translating C programs into Python, comparing the differences between the two languages, and verifying that the translated programs produce the correct output.

The session includes programs and activities covering:

* Google Colab setup and notebook workflow
* Translating C programs into Python
* Comparing C and Python structures
* Factorial and Fibonacci programs
* Converting a C struct into a Python dictionary
* Using AI to review and assist with code translation
* Comparing exact outputs between C and Python
* Documenting differences between the two languages
* Peer verification and output checking

The main principle of the session was:

> Translate what you know. Run it. Prove it.

Detailed information and the programs can be found in the [Session 4 folder](Session-4/).
